# Rsbuild

srvkit can be used with Rsbuild as a plugin.

## Installation

Install this package as a dev dependency in the project:

<PackageManagerTabs
    command={{
        npm: "npm i @srvkit/rsbuild",
        yarn: "yarn add @srvkit/rsbuild",
        pnpm: "pnpm add @srvkit/rsbuild",
        bun: "bun add @srvkit/rsbuild",
    }}
/>

## Configuration

Add the following code:

```ts title="rsbuild.config.ts"
import { defineConfig } from "@rsbuild/core";

import { pluginSrvkit } from "@srvkit/rsbuild/plugin";

export default defineConfig({
    plugins: [
        pluginSrvkit(),
    ],
});
```
